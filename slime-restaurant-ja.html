スライムレストラン プライバシーポリシー

最終更新日: 2026年7月31日

本アプリの運営者は、スマートフォン向けゲームアプリ「スライムレストラン」（以下「本アプリ」）における利用者情報を、以下のとおり取り扱います。

取得する情報

本アプリでは、機能提供、広告配信、不具合調査、利用状況の分析のため、次の情報を取得または利用する場合があります。

  • アプリの利用状況、ゲーム内イベント、広告の表示・視聴状況
  • 端末情報、OS、アプリバージョン、プラットフォーム、広告ID、IPアドレス
  • クラッシュログ、診断情報
  • プレイヤーID、認証アカウント情報（Google または Apple のログインにより提供されるメールアドレスおよびアカウントIDを含む場合があります）、クラウドセーブデータ、コード引き換えの入力コードと受け取り状況
  • アプリ内課金の商品ID、購入状態、購入確認に必要な情報
  • お問い合わせフォームまたはメールに入力された内容

利用目的

  • 本アプリの提供、保守、改善、不具合調査
  • クラウドセーブ、コード引き換え、課金復元およびアカウント認証の機能提供
  • 広告配信、広告効果測定、不正利用防止
  • お問い合わせ、要望、バグ報告への対応
  • 本アプリの利便性向上のための利用状況の分析

利用する外部サービス

本アプリでは、以下の外部サービスを利用する場合があります。これらのサービス提供者は、各サービスのプライバシーポリシーに従って情報を取り扱います。

  • Google AdMob / Google Mobile Ads
  • Unity Ads / ironSource
  • Firebase Authentication / Firestore / Cloud Functions / Analytics / Crashlytics / Remote Config
  • Unity IAP、Apple App Store、Google Play Billing
  • Google Forms

第三者提供

本アプリの運営者は、利用者情報を販売しません。本アプリの機能提供、広告配信、分析、不具合調査およびお問い合わせ対応に必要な範囲で、上記の外部サービス提供者が利用者情報を取り扱う場合があります。法令に基づく場合または利用者の同意がある場合を除き、それ以外の目的で利用者情報を第三者へ提供しません。

アカウントおよびデータの削除

利用者は、本アプリ内の「アカウント削除」から、アカウントおよび関連データの削除を開始できます。削除対象には、Firebase Authentication の認証アカウント、クラウドセーブデータ、プレイヤーIDに紐づくコード引き換え履歴を含みます。削除後は、クラウドセーブの復元および当該アカウントによる利用の継続はできません。

アプリを利用できない場合、またはお問い合わせ内容の削除を希望する場合は、下記の削除申請窓口から申請できます。申請の確認のため、プレイヤーIDその他の必要な情報をお尋ねする場合があります。

アプリストアが管理する購入取引記録、法令上または不正利用防止のために保持が必要な情報、匿名化または集計済みで個人を特定できない分析情報については、削除対象外となる場合があります。
