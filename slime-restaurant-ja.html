スライムレストラン プライバシーポリシー

最終更新日: 2026年7月22日

本アプリの運営者は、スマートフォン向けゲームアプリ「スライムレストラン」（以下「本アプリ」）における利用者情報を、以下のとおり取り扱います。

取得する情報

本アプリでは、機能提供、広告配信、不具合調査、利用状況の分析のため、次の情報を取得または利用する場合があります。

  • アプリの利用状況、ゲーム内イベント、広告の表示・視聴状況
  • 端末情報、OS、アプリバージョン、プラットフォーム、広告ID、IPアドレス
  • クラッシュログ、診断情報
  • プレイヤーID、クラウドセーブデータ、コード引き換えの入力コードと受け取り状況
  • アプリ内課金の商品ID、購入状態、購入確認に必要な情報
  • お問い合わせフォームに入力された内容

利用目的

  • 本アプリの提供、保守、改善、不具合調査
  • クラウドセーブ、コード引き換え、課金復元などの機能提供
  • 広告配信、広告効果測定、不正利用防止
  • お問い合わせ、要望、バグ報告への対応

利用する外部サービス

本アプリでは、以下の外部サービスを利用する場合があります。各サービスで取得される情報は、各提供元のプライバシーポリシーに従って取り扱われます。

  • Google AdMob / Google Mobile Ads
  • Unity Ads / ironSource
  • Firebase Authentication / Firestore / Cloud Functions / Analytics / Crashlytics / Remote Config
  • Unity IAP、Apple App Store、Google Play Billing
  • Google Forms

第三者提供

法令に基づく場合、利用者の同意がある場合、または本ポリシーに記載した外部サービスの利用に必要な場合を除き、取得した情報を第三者に提供しません。

データの削除

クラウドセーブデータ、プレイヤーIDに紐づくデータ、お問い合わせ内容の削除を希望する場合は、下記のお問い合わせ先よりご連絡ください。確認のため、プレイヤーID等の情報をお尋ねする場合があります。
